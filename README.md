# ⏱️ Timodoro

Timodoro is a simple and focused Pomodoro-style productivity app built with Flutter. It helps you manage your time using structured work, rest, and reflection cycles — keeping you productive without unnecessary distractions.

---

## ✨ Features

- 🧠 Customizable focus sessions (work, rest, notes)
- 💾 Local settings storage using JSON
- 📱 Clean, minimal UI
- ⚡ Lightweight and fast
- 🪟 Cross-platform support (Windows, Android, iOS, Linux, Web*)

---

## 🧩 How It Works

Timodoro lets you configure:

- **Work Time** → focused productivity session
- **Rest Time** → short breaks between sessions
- **Notes Time** → reflection / journaling period
- **Screens** → number of display's you have

Settings are saved locally on your device using a JSON file stored in the app documents directory.

---

## 📦 Tech Stack

- Flutter
- Dart
- path_provider (for local storage)
- JSON (for settings persistence)

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/timodoro.git
cd timodoro
```

### 2. install dependencies

```bash
flutter pub get
```

### 3. Run the app
```bash
flutter run
```
